# System for Management and Control of IoT Modules

This repository contains the source code for a **Blazor Server application** developed as part of a master's thesis.  
The thesis focuses on the design and implementation of a system for the **management and control of IoT devices**.

## Project Overview
The system provides a platform for managing IoT modules and integrating them with other server components.  
It consists of a server application and software for selected IoT devices.  

### Features
- **Web application interface** for users  
- **Visualization of collected data** from IoT devices  
- **Device management** (configuration and control of individual modules)  
- **Integration support** between IoT modules and server components
